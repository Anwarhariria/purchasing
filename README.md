# SPAKE - Sistem Pengadaan Kampus Terpadu
Universitas Asa Indonesia (ASAINDO)

SPAKE adalah aplikasi front-end sistem pengadaan barang dan logistik internal kampus yang mendukung alur kerja 4 peran (Staf Pemohon, Bagian Umum, Bagian Keuangan, dan Super Admin IT) serta monitoring 6 tahapan siklus pengadaan terintegrasi dengan pemeringkatan Simple Additive Weighting (SAW).

## Fitur Utama

- **Dashboard Berbasis Peran**:
  - Pemohon (Staf / Asisten Lab)
  - Bagian Umum (Sarpras & Pengadaan)
  - Bagian Keuangan (Verifikasi & ACC Anggaran)
  - Super Admin (IT & Manajemen Pengguna)
- **Monitoring Siklus 6 Tahapan Pengadaan**
- **Sistem Prioritas Belanja (Algoritma SAW)**
- **Ekspor Rekap Laporan Pengadaan (.CSV)**

## Pengembangan Lokal

```sh
npm install
npm run dev
```

Server pengembangan lokal akan berjalan pada `http://localhost:8080/`.
